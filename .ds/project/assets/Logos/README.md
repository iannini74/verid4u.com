# Logos

O símbolo do VerID4U em suas variantes. Todos herdam cor quando aplicados
inline; os arquivos trazem o cobalto `#1D5BE0` embutido para uso avulso.

- **verid4u-mark** — padrão, de 24 px para cima.
- **verid4u-mark-solid** — favicon e usos pequenos.
- **verid4u-mark-inverse** — sobre fundo de marca.
- **verid4u-seal** — selo de estado; use `currentColor` para que assuma a cor
  do veredito (verde, âmbar, cinza ou vermelho).

O logotipo «VerID4U» é tipografia composta em Inter Tight, não um arquivo.
O porquê está no README do sistema.
