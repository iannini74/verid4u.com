Etiqueta compacta de estado, para listas e tabelas do painel — onde o selo
cheio ocuparia espaço demais.

Usa o mesmo par cor/tint dos vereditos, de modo que a lista do emissor e a
página pública falem a mesma língua. Em tabela, a palavra basta: o ícone
voltaria a ser necessário só se a etiqueta aparecesse isolada, sem cabeçalho
de coluna que a nomeie.

A etiqueta `demo` existe para marcar registros de demonstração. Ela é
obrigatória: um certificado fictício exibido como «Verificado» num site
público, sem aviso, seria exatamente a fraude que a plataforma existe para
combater.
